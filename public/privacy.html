🌐 Honest Disclosure: External Services

⚠️ Being fully transparent: we do call external APIs in specific scenarios. Here is exactly what, when, and why.

1. Icon Search APIs (Only When You Search)

When you manually click search in the Icon Search panel, your search query is sent to these public APIs:

ServiceDomainWhat Is SentPrivacy
Iconifyapi.iconify.designSearch query text only (e.g., "home")Policy
theSVGthesvg.orgSearch query text onlyInfo
Simple Iconscdn.simpleicons.orgIcon name only (CDN fetch)Info

What is NOT sent: Your IP is logged by their servers (standard HTTP). No personal data, no cookies, no SVG content, no identifiers. These calls only happen when you actively search — if you never use icon search, zero external calls are made.

2. Google Fonts (For Hindi/Multi-language Text)

ServiceDomainWhat Is Sent
Google Fonts CSSfonts.googleapis.comFont name requests
Google Font Filesfonts.gstatic.comFont file downloads

Honest note: Google may log your IP address when fetching fonts (per Google's Privacy Policy). We cache fonts via Service Worker so they load from your device after the first visit. If you want to avoid Google entirely, the app falls back to system fonts.

3. PNG Export — Font Embedding

When you export as PNG, the app may download Google Font files to embed them as base64 data in the PNG. This ensures Hindi/English fonts render correctly in the downloaded image. Same Google Fonts infrastructure as above.

🔐 Content Security Policy (CSP)

We enforce a strict CSP via <meta> tag that limits what the browser can load:

  • ✗ No unauthorized external scripts
  • ✗ No inline event handlers (onclick, etc.)
  • ✗ No connections to unauthorized servers
  • ✓ Only allowlisted domains: icon APIs + Google Fonts

The CSP is the technical enforcement that makes our privacy promises verifiable — not just words on a page.

🛡 SVG Security

All SVG code rendered in the app preview is sanitized before display:

  • on* event attributes are stripped (onclick, onload, etc.)
  • javascript: URLs are blocked
  • Content is rendered via dangerouslySetInnerHTML after sanitization

🌐 Offline Capability

After your first visit, the app works 100% offline. The Service Worker caches:

  • App shell (HTML, CSS, JavaScript)
  • Previously fetched icon SVGs
  • Google Fonts (CSS + font files)

Offline features: editing SVG code, drawing, customizing, code generation, SVG/PNG export. Icon search requires internet.
