# Contributing to Live SVG Editor

Thank you for your interest in contributing! This project follows the PrivMITLab privacy-first principles.

## 🛠 Development Setup

1. Fork and clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Make your changes
5. Build and test: `npm run build`
6. Submit a pull request

## 📐 Code Guidelines

- Use TypeScript for all new code
- Follow existing code style (2-space indentation)
- No external dependencies — everything must be client-side
- No tracking, analytics, or data collection code
- Write descriptive commit messages

## 🔒 Privacy Rules

All contributions must adhere to:
- **NO** analytics or tracking scripts
- **NO** cookies (except localStorage for user preferences)
- **NO** server-side processing
- **NO** external API calls
- **NO** advertisements

## 🧪 Testing

- Test in both light and dark modes
- Test responsive layouts (mobile + desktop)
- Verify keyboard shortcuts work
- Check offline functionality

## 📝 Pull Request Process

1. Create a feature branch
2. Make your changes
3. Ensure the build passes (`npm run build`)
4. Update documentation if needed
5. Submit PR with a clear description
